# Autoscroll Extension Icons

This directory contains the icon files for the autoscroll extension.

## Required Icon Sizes

- **icon16.png** - 16x16 pixels (toolbar icon)
- **icon32.png** - 32x32 pixels (Windows and Linux)
- **icon48.png** - 48x48 pixels (extension management page)
- **icon128.png** - 128x128 pixels (Chrome Web Store)

## Icon Design Guidelines

- Use a simple, recognizable design
- Ensure icons are visible at small sizes
- Use consistent colors and style
- Consider both light and dark themes
- Make sure icons are clear and not cluttered

## Usage

Icons are referenced in:
- `manifest.json` - Extension icons
- `popup.html` - Popup header icon
- Chrome Web Store listing

## Design Suggestions

For autoscroll extension, consider using:
- Scroll-related symbols (arrows, scroll bars)
- Play/pause controls
- Smooth, flowing lines
- Modern, minimalist design
- Blue/purple color scheme to match the extension theme
